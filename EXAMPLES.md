# Starter Translation Examples

These short English source sentences were written for this repository. They are original examples, not translations copied from another project. The Hinglish versions are draft proposals meant to show the project's style; they are open to review and regional alternatives.

## File backup

**English:** Before installing an update, save a backup of important files. If something goes wrong, the backup may help you restore them.

**Hinglish:** Update install करने से पहले ज़रूरी files का Backup बना लें। अगर कुछ गड़बड़ हो जाए, तो Backup से files वापस पाने में मदद मिल सकती है।

## App permissions

**English:** Before allowing an app to access your location, check whether it needs that access for a feature you use.

**Hinglish:** किसी App को अपनी location access करने की permission देने से पहले देखें कि आपके इस्तेमाल वाले feature के लिए इसकी ज़रूरत है या नहीं।

## Passwords

**English:** Use a different password for each account. A Password Manager can help you store them securely.

**Hinglish:** हर Account के लिए अलग Password रखें। Password Manager उन्हें सुरक्षित तरीके से store करने में मदद कर सकता है।

## Review notes

These are concise style examples, not complete technical guides. Reviewers should check that each translation sounds natural for its intended audience and preserves the source meaning. Suggestions for regional alternatives are welcome.
