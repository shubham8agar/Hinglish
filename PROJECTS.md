## Work states

- **Researching**: checking exact content reuse rights, contribution channel, duplicate work, and task assignment. Hinglish acceptance is checked to frame the proposal, not as a prerequisite to prepare a sample PR.
- **Ready to draft**: exact source-content reuse rights and an appropriate contribution channel are clear, and the target task issue is assigned to the contributor (with any required maintainer approval). Hinglish need not already be accepted; the sample PR may propose support.
- **Local draft / review**: a small translation exists in this repository and awaits linguistic/domain review.
- **Target task/support issue proposed/open**: a target-project issue defines the README sample task and may ask maintainers to list/support Hinglish; this is separate from intake here and does not count as accepted locale support.
- **Upstream PR open**: a human approved the exact change and it was submitted; include the PR URL and date.
- **Merged**: upstream merged it; include the PR URL.
- **Paused**: work is blocked or waiting for maintainers/community input; state why.
- **Not aligned**: the project's language model or contribution process conflicts with this project's approach.

For each project selected for work, keep a local plan under `plans/<owner>-<repo>/PLAN.md`. The default sample is the full primary README; record the local intake issue, exact source URL/revision, evidence that the README content may be adapted, locale-policy evidence or uncertainty, audience, review needs, target task/support issue, assignment, and sample-PR status. Do not translate license text or notices. Once rights, channel, duplicate-work, and assignment checks clear, proceed to the README draft without waiting for Hinglish acceptance. When changing a tracker status, include the date, evidence link, owner/reviewer if known, active task issue when applicable, and next action. This table is only an aggregate status view. Update it through this repository's contribution workflow. Do not mark a project ready based on stars or general repository licensing alone. Do not count local drafts as upstream contributions.

## Future domains

Law, health, public services, and other high-impact areas have no approved upstream targets yet. Add a project only after checking jurisdiction or audience, source rights, accepted language variant, and qualified reviewer availability. A translation must not imply professional advice or legal equivalence.
